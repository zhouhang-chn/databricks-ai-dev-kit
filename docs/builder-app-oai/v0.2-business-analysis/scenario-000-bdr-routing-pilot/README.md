# Scenario Bundle: ML-Based BDR Routing Pilot

This folder is the canonical seed bundle for v0.2 business-analysis
preparation.

## Source of Truth

Only `User_Input.md` is human-authored input. All other files are generated or
regenerated by agents from:

- `User_Input.md`
- repository source code
- Databricks data and metadata
- analyst review notes

Descriptive analyst context is markdown:

- `Business_Scenario.md`

Machine-checkable assets and evals are YAML:

- `Context_Assets.yaml`
- `evals.yaml`

## Generation Order

1. `User_Input.md`
2. `Business_Scenario.md`
3. `Context_Assets.yaml`
4. `evals.yaml`

Manual analyst execution can update `Business_Scenario.md`,
`Context_Assets.yaml`, and `evals.yaml` when the analyst discovers missing
context, rejected paths, or validation rules.

## Folder Convention

Scenario bundle ids use:

```text
scenario-<three digit sequence>-<short slug>
```

Runtime ids inside artifacts use snake_case, for example
`ml_based_bdr_routing_pilot`. The bundle id is stable for folder-level review
and portability; runtime ids are stable for retrieval, evals, and traces.
