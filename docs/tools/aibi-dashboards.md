# `aibi_dashboards/` — AI/BI dashboards

Source: [`databricks_tools_core/aibi_dashboards/`](../../databricks-tools-core/databricks_tools_core/aibi_dashboards/)

AI/BI (formerly Lakeview) dashboard CRUD. The dashboard JSON document itself is generated by the AI assistant (the `databricks-aibi-dashboards` skill teaches the schema); this module deals only in *serialised dashboards*.

Files:

- `dashboards.py` — CRUD, publish/unpublish, the high-level `deploy_dashboard` / `create_or_update_dashboard` entry points.
- `models.py` — `DashboardDeploymentResult` dataclass.

| Function | Notes |
|----------|-------|
| `deploy_dashboard(display_name, parent_path, serialized_dashboard, warehouse_id=None, publish=True, genie_space_id=None)` | Single call: idempotent create-or-update, optional Genie space injection (`_inject_genie_space`), optional publish. Returns `DashboardDeploymentResult`. |
| `create_or_update_dashboard(...)` | Same as `deploy_dashboard` but without the publish/Genie-injection convenience — use this when you only want the asset in place. |

## Conventions

- **Dashboard JSON is the assistant's job.** The skill (`databricks-aibi-dashboards`) describes the schema; this module never validates or rewrites the JSON beyond Genie injection. Pass it through unchanged.
- **Genie injection is a string transform.** When `genie_space_id` is provided to `deploy_dashboard`, `_inject_genie_space` wires the Genie tile into the serialised dashboard before sending it. Don't pre-inject — the helper is idempotent.
- **Workspace path layout.** `parent_path` is a workspace folder (`/Workspace/Users/me/dashboards`). Display names need not be unique, but combinations with parent path effectively are.
